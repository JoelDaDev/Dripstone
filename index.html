> ABOUT THIS TERMINAL

────────────────────────────────────────

DRIPSTONE is a data repository for hosting JSON data used by MDIRT.

Browse or search the file index on the left. Click any entry to load and explore its data in the viewer. Use LINK to copy a direct URL to any file, or COPY RAW to copy the JSON to your clipboard.

────────────────────────────────────────

> DIRECT DATA ACCESS

All JSON files are publicly accessible at their raw paths. You can fetch any file directly via:

// Example fetch
fetch("https://joelalexander.dev/dripstone/data/<filename>.json")
  .then(res => res.json())
  .then(data => console.log(data));
