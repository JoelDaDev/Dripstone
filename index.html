About Dripstone

Dripstone is a data repository for hosting JSON reference data used by MDIRT.

Browse or search the file list on the left. Click any entry to view its contents. Use Copy link to share a direct URL to any file, or Copy JSON to copy the raw data to your clipboard.

Direct data access

All JSON files are publicly accessible at their raw paths:

fetch("https://joelalexander.dev/dripstone/data/<filename>.json")
  .then(res => res.json())
  .then(data => console.log(data));
